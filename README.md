# 🎮 Alan Wake 2: Musical Scene Recreation (Unity Demo)

This Unity project is a **fan-made, non-commercial recreation** of the musical sequence seen in *Alan Wake 2*. It was created for **educational and portfolio** purposes only. The project attempts to simulate the dynamic musical environment presented in the iconic scene known as *“The Musical”* by *Gods of Asgard*, inspired by Remedy Entertainment’s masterful narrative design.

---

## 📖 Overview

This interactive scene is a creative experiment that combines gameplay, musical timing, and cinematic tools inside Unity. Players can activate musical segments as part of a continuous sequence—mimicking the stage performance flow seen in *Alan Wake 2*.

---

## 🛠️ Features

- 🎼 **Synchronized Musical Triggers**  
- 🎥 **Timeline + Cinemachine Sequences**  
- ⏱️ **Seamless Transition Handling (Unity Level Sequences)**  
- 🧠 **AAA-inspired Musical Setpiece Logic**

## 🎓 Educational Purpose

This scene was developed to:
- Analyze *Alan Wake 2’s* interactive music design.
- Understand Unity’s Timeline, Media Player, and Sequence Systems.
- Experiment with narrative transitions using triggers and events.
- Demonstrate scene direction in game-like musical theatre.

---

## 🚀 How to Run

1. Clone or download the project.
2. Open in Unity 2022.3+ (LTS Recommended).
3. Open the scene: `Scenes/MusicalStage.unity`.
4. Press **Play** to test the level trigger and sequence logic.
